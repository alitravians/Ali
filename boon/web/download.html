اختر نظامك، شغّل المثبّت، اضغط Patch. هذا كل شيء.

كيف أستخدم المثبّت؟

  1. أغلق Discord بالكامل قبل التثبيت.
  2. شغّل ملف boon-installer-* الذي حمّلته.
  3. المثبّت يكتشف Discord تلقائياً. اضغط ١ (Patch).
  4. افتح Discord مرة ثانية، ثم اضغط Ctrl+Shift+B لفتح لوحة BOON.
على Windows: عند أول تشغيل قد يظهر تحذير "Windows protected your PC". اضغط More info ثم Run anyway. هذا تحذير عادي للبرامج مفتوحة المصدر بدون شهادة Microsoft المدفوعة — مرة وحدة فقط، لا يتكرر.
على macOS: انقر بزر الفأرة الأيمن على الملف ثم اختر Open بدل النقر المزدوج في أول مرة.
للحذف: شغّل المثبّت ثانية واضغط ٢ (Unpatch). يعيد دسكورد للحالة الأصلية بلا أثر.

طرق تثبيت أخرى

Discord Web (متصفح) — Userscript
  1. ثبّت Tampermonkey أو Violentmonkey على متصفحك.
  2. افتح هذا الرابط مباشرة: boon.user.js
  3. Tampermonkey يعرض زر "Install". اضغطه.
  4. افتح discord.com/app ثم Ctrl+Shift+B.
Browser Extension

نسخة Chrome/Edge من البيلد متاحة في boon/dist/extension داخل المستودع. ثبّتها يدوياً من chrome://extensions (Developer mode → Load unpacked).

Build من المصدر بنفسك 
git clone https://github.com/alitravians/Ali.git
cd Ali/boon
npm ci
npm run build
# الناتج في dist/desktop/

cd ../boon-installer
go build -o boon-installer .
# شغّل: BOON_LOCAL_BUILD_DIR=../boon/dist/desktop ./boon-installer -patch
