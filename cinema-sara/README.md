# Cinema Sara (سينما سارة)

تطبيق حجز ومشاهدة الأفلام للهواتف النقالة (أندرويد، آيباد، آيفون)

## المميزات الرئيسية

### للمستخدمين
- **حجز الأفلام**: اختر الفيلم والوقت المناسب لك
- **نظام الدخول بالكود**: كل كود يسمح لـ 5 مستخدمين بالمشاهدة معاً
- **مشغل الأفلام**: عد تنازلي 60 ثانية قبل بدء المشاهدة
- **دعوة الأصدقاء**: ادعُ حتى 10 أصدقاء عبر البريد الإلكتروني أو Discord أو Instagram
- **مراجعة حالة الحجز**: تحقق من حالة طلب الحجز الخاص بك
- **قوانين المنصة**: اطلع على قواعد استخدام المنصة

### للإدارة
- **لوحة تحكم شاملة**: كود الدخول للإدارة هو "3131"
- **إدارة الأفلام**: إضافة، تعديل، وحذف الأفلام (دعم روابط شاهد ويوتيوب)
- **مراجعة الحجوزات**: الموافقة أو الرفض مع توليد كود الدخول تلقائياً
- **التحكم بالتطبيق**: فتح أو إغلاق التطبيق مع رسالة مخصصة

## البنية التقنية

### Backend (FastAPI)
- **المسار**: `cinema-sara-backend/`
- **قاعدة البيانات**: In-memory (البيانات تُفقد عند إعادة التشغيل)
- **المنافذ**: يعمل على المنفذ 8000

### Frontend (React + TypeScript)
- **المسار**: `cinema-sara-frontend/`
- **التقنيات**: React, Vite, Tailwind CSS, shadcn/ui
- **المنافذ**: يعمل على المنفذ 5173 (تطوير)

### Mobile (Capacitor)
- **المنصات**: Android, iOS, iPad
- **المسار**: `cinema-sara-frontend/android/`

## التشغيل المحلي

### 1. تشغيل Backend

```bash
cd cinema-sara-backend
poetry install
poetry run fastapi dev app/main.py
```

سيعمل Backend على: http://localhost:8000

### 2. تشغيل Frontend

```bash
cd cinema-sara-frontend
npm install
npm run dev
```

سيعمل Frontend على: http://localhost:5173

### 3. اختبار التطبيق

افتح المتصفح على: http://localhost:5173

**اختبار تدفق المستخدم:**
1. الصفحة الرئيسية → احجز فلمك
2. املأ النموذج واختر الفيلم والوقت
3. مراجعة حالة قبول الفيلم (أدخل البريد الإلكتروني)
4. بعد الموافقة من الإدارة، استخدم الكود للدخول
5. شاهد العد التنازلي 60 ثانية ثم بدء الفيلم

**اختبار لوحة الإدارة:**
1. الصفحة الرئيسية → انقر على أيقونة القفل في الأسفل
2. أدخل كود الإدارة: "3131"
3. جرب إضافة/تعديل/حذف الأفلام
4. راجع الحجوزات ووافق/ارفض الطلبات
5. جرب فتح/إغلاق التطبيق

## بناء تطبيق Android (APK)

### 1. بناء Frontend للإنتاج

```bash
cd cinema-sara-frontend
npm run build
```

### 2. مزامنة Capacitor

```bash
npx cap sync android
```

### 3. بناء APK

```bash
cd android
./gradlew assembleDebug
```

سيتم إنشاء APK في: `android/app/build/outputs/apk/debug/app-debug.apk`

### 4. تثبيت على جهاز Android

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

## النشر (Deployment)

### Backend Deployment

يمكن نشر Backend باستخدام أي خدمة تدعم FastAPI:
- Fly.io
- Railway
- Render
- Heroku

**ملاحظة مهمة**: قبل النشر، يجب استبدال قاعدة البيانات In-memory بقاعدة بيانات دائمة (PostgreSQL, MySQL, إلخ)

### Frontend Deployment

1. حدّث ملف `.env` بعنوان Backend المنشور:
```
VITE_API_URL=https://your-backend-url.com
```

2. ابنِ التطبيق:
```bash
npm run build
```

3. انشر مجلد `dist` على أي خدمة استضافة:
- Vercel
- Netlify
- Cloudflare Pages
- GitHub Pages

## التحديثات المستقبلية

### تحديثات الويب (تلقائية)
عند استخدام Capacitor، التطبيق يحمّل المحتوى من URL الويب. لذلك:
- **تحديثات UI والميزات**: فقط أعد نشر الموقع، المستخدمون سيرون التحديثات تلقائياً
- **لا حاجة لإعادة بناء APK** للتحديثات العادية

### تحديثات APK (عند الحاجة فقط)
أعد بناء APK فقط عند:
- تغيير أيقونة التطبيق أو شاشة البداية
- تحديث إعدادات Capacitor
- إضافة plugins جديدة

## الملاحظات المهمة

### قاعدة البيانات In-Memory
⚠️ **تحذير**: البيانات الحالية تُفقد عند إعادة تشغيل Backend. هذا مقبول للنموذج الأولي (Proof of Concept) لكن يجب استبداله بقاعدة بيانات دائمة للإنتاج.

### كود الإدارة
كود الإدارة الحالي "3131" مكتوب مباشرة في الكود. للإنتاج، يجب:
- تخزينه في متغيرات البيئة
- استخدام نظام مصادقة أكثر أماناً

### CORS
إعدادات CORS الحالية مفتوحة للجميع (`allow_origins=["*"]`). هذا مقبول للتطوير لكن يجب تقييده للإنتاج.

### صلاحية الكود
- كل كود صالح لمدة 7 أيام
- كل كود يسمح لـ 5 مستخدمين بالمشاهدة معاً
