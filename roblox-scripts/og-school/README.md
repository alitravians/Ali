# OG School Hub — لوحة تحكم سكربت المدرسة

واجهة تحكم احترافية مبنية من الصفر بلغة Luau للعبة
[OG-School](https://www.roblox.com/games/139529206391254/OG-School) (PlaceId `139529206391254`).

السكربت **عام (Universal)** ويعمل في أي لعبة، لكنه مصمَّم ومُترجَم خصيصًا للمدرسة
بثيم السبورة (أزرق داكن + سماوي طباشيري) ونصوص عربية كاملة (RTL).

## التشغيل

انسخ هذا السطر والصقه في المنفّذ (Executor):

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/alitravians/Ali/arabic-localization/roblox-scripts/og-school/loader.lua"))()
```

اللودر يجلب أحدث نسخة من `main.lua` تلقائيًا، فأي تحديث يصلك بدون تغيير الرابط.

اضغط مفتاح **K** لإظهار/إخفاء القائمة.

## الميزات

| التبويب | الميزات |
| --- | --- |
| 🏠 الرئيسية | نظرة عامة (معرّف اللعبة/السيرفر) + تشغيل سريع للسرعة/الطيران/ESP |
| 🏃 الحركة | السرعة (منزلق)، الطيران (منزلق)، اختراق الجدران، قفز لا نهائي، المشي على الجدران |
| 👥 اللاعبون | قائمة لاعبين حيّة، انتقال لِلاعب، مراقبة لاعب، أسماء/صناديق ESP |
| 👁️ الرؤية | إضاءة كاملة، إزالة الضباب، زاوية الرؤية (FOV)، كاميرا حرة |
| 🖧 السيرفر | إعادة الانضمام، تبديل سيرفر، منع الطرد بالخمول، نسخ Job ID |
| ⚙️ الإعدادات | لون الواجهة، حفظ الإعدادات، إغلاق السكربت |

## التحكم

- **WASD** أو **الأسهم**: الحركة أثناء الطيران/الكاميرا الحرة
- **مسافة (Space)** / **Shift**: أعلى/أسفل أثناء الطيران
- **مسافة (Space)** / **Ctrl**: أعلى/أسفل أثناء الكاميرا الحرة، والأسهم للنظر
- **K**: إظهار/إخفاء القائمة

## ملاحظات

- كل العمليات محميّة بـ `pcall` وتعمل بعد الـ Respawn.
- الإعدادات تُحفَظ تلقائيًا (إن دعم المنفّذ `writefile`).
- ميزات خاصة بميكانيكا اللعبة (فلوس/مهام/أبواب) تحتاج تحليل الـ RemoteEvents — متوفّرة عند الطلب.
