# تعلم الوضوء والصلاة

تطبيق تعليمي إسلامي لتعليم الوضوء والصلاة للأطفال والكبار.

## التشغيل السريع

```bash
npm install
npm run dev
```

## بناء APK / AAB

```bash
npm run build-apk    # APK للتجربة
npm run build-aab    # AAB للرفع على Google Play
```

انظر [DEVELOPER.md](./DEVELOPER.md) للتعليمات التفصيلية وهيكل المشروع.
