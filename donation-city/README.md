# 🎬 مدينة التبرعات — Donation City (لعبة Roblox)

لعبة سينما/مدينة تفاعلية على Roblox، فيها نظام كوينز، تذاكر، مقاعد سينما، متجر بالـ Robux،
نظام رتب وإدارة، أقسام فريق عمل، ووضع صيانة دائم. كل واجهات اللعبة بالعربي مع دعم RTL.

- **اسم اللعبة:** مدينة التبرعات
- **Game / Place ID:** `10237943037`
- **الإصدار الحالي:** `٢.٩.٩` (v2.9.9)
- **ملف اللعبة:** `DonationCity_FINAL.rbxlx` (يُفتح في Roblox Studio)
- **كود لوحة الإدارة داخل اللعبة:** `3131` (لا يُعرض بصرياً — للمالك/الأدمن فقط)

> ⚠️ ملاحظة مهمة: مزايا الحفظ الدائم (DataStore) والمزامنة بين السيرفرات (MessagingService)
> — مثل **وضع الصيانة** و**الكوينز** و**التذاكر** — تشتغل فقط في **اللعبة المنشورة (Published)**
> مع تفعيل **Enable Studio Access to API Services** من Creator Dashboard. ما تثبت في معاينة الاستديو لحالها.

## 🛠️ طريقة الاستخدام (البناء والنشر)

المصدر الحقيقي للكود هو مجلد `src/`. ملف اللعبة `.rbxlx` يحتوي نسخة محقونة من هذه السكربتات.
لتعديل أي سكربت: **عدّل في `src/` ثم ابنِ** — لا تعدّل داخل ملف الـ rbxlx يدوياً.

### 1) عدّل الكود
عدّل الملف المطلوب داخل `src/` (مثلاً `src/CinemaServices.server.lua`).

### 2) ابنِ ملف اللعبة
```bash
cd donation-city
python3 build_all.py
```
- السكربت يبحث عن **علامة فريدة (marker)** داخل كل كتلة `<![CDATA[ ... ]]>` في ملف الـ rbxlx
  ويستبدل محتواها بمصدر الملف المقابل من `src/`. قائمة الربط موجودة في أعلى `build_all.py` (متغير `UPDATES`).
- لإضافة سكربت **جديد** للبناء: لازم يكون له كتلة Script موجودة مسبقاً في الـ rbxlx فيها العلامة الفريدة،
  ثم تضيف سطره في `UPDATES`. (مثال: `("src/TicketSystem.server.lua", "TICKET SYSTEM (Server)")`.)

### 3) انشر
- افتح `DonationCity_FINAL.rbxlx` في **Roblox Studio**.
- اضغط **Publish to Roblox** على نفس اللعبة (Place ID `10237943037`).
- للتجربة الصحيحة: شغّل اللعبة من **تطبيق/موقع روبلوكس** (مو زر Play داخل الاستديو)،
  خصوصاً لمزايا DataStore والشراء بالـ Robux.

### متطلبات بيئية مهمة (مرة واحدة)
في Creator Dashboard → لعبتك → **Settings → Security**:
- فعّل **Enable Studio Access to API Services** ثم **Save**.
- بدون هذا الخيار: الكوينز/التذاكر/وضع الصيانة ما يثبتون بين الجلسات.

## 💳 الاقتصاد والشراء

### اختيار المقعد (هجين: كوينز أو تذكرة)
عند اختيار مقعد من البروجكتر تظهر نافذة «اختر طريقة الدفع»:
- 💰 **ادفع ٣٠ كوينز** (١٥ لأعضاء VIP — نص السعر).
- 🎟️ **استخدم تذكرة** (يتعطّل لو ما عند اللاعب تذاكر).
- السيرفر يتحقق من الرصيد ويخصم فعلياً قبل إجلاس اللاعب. (`paySeat` في `CinemaSystem.server.lua`.)

### نظام التذاكر (`TicketSystem.server.lua`)
- محفوظ بـ DataStore باسم `CinemaTickets_v1`.
- **مكافأة يومية:** كل `86400` ثانية (٢٤ ساعة) يحصل اللاعب على `+3` تذاكر تلقائياً.
- **السقف الأقصى:** `10` تذاكر.
- لاعب جديد يبدأ بـ `3` تذاكر.
- واجهة برمجية عامة (لباقي السكربتات): `_G.GetTickets`, `_G.UseTicket`, `_G.AddTickets`, `_G.NotifyPlayer`, `_G.TicketMax`.

## 🛡️ وضع الصيانة (Maintenance)
- **دائم** عبر DataStore + **مزامنة فورية** بين كل السيرفرات عبر MessagingService.
- يبقى مقفلاً حتى بعد إعادة تشغيل السيرفرات — لا يُفتح إلا لما المالك يطفّيه يدوياً.
- وقت الصيانة **كل اللاعبين يتجمّدون** (وحتى الأدمن)؛ زر «👑 دخول الإدارة» يفتح اللوحة لإلغاء الصيانة فقط.
- يُدار من لوحة الإدارة (كود `3131`).

## 👥 الرتب وأقسام الفريق
- رتب: `owner` / `admin` / `mod` / `staff` + `vip`، محفوظة بالـ DataStore.
- **أقسام فريق العمل مخصّصة بالكامل:** المالك ينشئ الأقسام، يوزّع الأعضاء يدوياً، ويكتب «المسؤولية» لكل عضو.
- الأقسام الفاضية تظهر في صفحة «👥 الفريق» بعنوانها.
