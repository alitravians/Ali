# Duel Wings — اكسسوار UGC (جناح ملائكي/شيطاني)

اكسسوار ظهر (Back Accessory) بجناحين متضادين:
- **الأيمن (ملائكي)**: قاعدة قرمزية + ريش عاجي + حواف ذهبية
- **الأيسر (شيطاني)**: ريش مدبب أسود فحمي/بنفسجي داكن + عروق برق بنفسجية

## الملفات
| ملف | الوصف |
|---|---|
| `DuelWings.fbx` | نسخة الكتالوج: ميش واحد مدموج (التكستشر مدمج) |
| `DuelWings_Game.fbx` | نسخة اللعبة: ميشان منفصلان (الجناحان + البرق) — اجعل البرق Neon داخل التجربة |
| `DuelWings.blend` | ملف Blender المصدر (4.2) |
| `WingsPalette.png` | خريطة الألوان الواحدة (256×256) |
| `wings_final.py` | سكربت البناء الكامل (Blender headless) |
| `render_wings.png` | الصورة المرجعية المعتمدة |
| `final_check.png` | رندر التحقق من الميش النهائي |

## المواصفات (مطابقة لمتطلبات Marketplace للاكسسوار الصلب)
- ميش واحد: **2128 مثلث** (الحد 4000)
- تكستشر واحد 256×256 (الحد 2048)
- المقاس: ~9.8 × 3.9 × 0.33 ستد (حد Back: ‏10×7×4.5)
- مركز الميش على نقطة الأصل (نقطة التثبيت: BodyBackAttachment)

## الاستيراد في Studio
1. Avatar → 3D Importer → اختر `DuelWings.fbx`
2. حوّله لاكسسوار: Accessory Fitting Tool → النوع Back → التثبيت BodyBackAttachment
3. لإبراز توهج البرق داخل تجربة: اجعل خامة القطع البنفسجية Neon (داخل اللعبة فقط — الكتالوج يتطلب Plastic)

## إعادة البناء
```bash
blender -b -P wings_final.py
```
