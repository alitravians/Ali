## 2) ⚠️ القواعد الإلزامية (لا تتجاوزها أبداً)

هذه قواعد فرضها صاحب المشروع عبر الجلسات، والالتزام بها شرط أساسي:

1. **عدّل في `src/` فقط — لا تعدّل داخل ملف الـ `.rbxlx` يدوياً.** بعد التعديل شغّل `build_all.py`.
2. **لا تنسخ أنظمة إدارة جاهزة** (Adonis / HD Admin / Kohl's). أي ميزة إدارية تُبنى داخل أنظمتنا نفسها بلمسة احترافية أصلية.
3. **أمان الموديلات الخام (`*.rbxmx` / `*.rbxm`):** موديلات Creator Store غالباً فيها **باك-دور** (عائلة `LightConfig`/`Type`/`Layout`/`EasyConfiguration`/`Structure`/`Pose` التي تستعمل `require(assetId)` عبر قيمة `NumberPose` متنكّرة = تنفيذ كود خارجي). القاعدة:
   - **ديكور ثابت** (مثل الحوض): جرّد **كل** السكربتات بالكامل (`inject_aquarium.py` يفعل ذلك عبر مجموعة `STRIP`).
   - **موديل له سلوك مشروع** (مثل شباك التذاكر بأبوابه/أصواته): احذف **فقط** الباك-دور المؤكّد وأبقِ السكربتات النظيفة كما هي، ثم افحص المتبقّي من `require(`/`loadstring`/`getfenv`/`HttpGet` (`inject_ticketbooth.py`).
   - **لا يصل أي كود خبيث للسيرفر إطلاقاً.** كل BasePart يُثبّت `Anchored=true`.
4. **عند مشاركة المستخدم صورة مرجعية لتصميم:** استخرج الفكرة ولا تنسخها ١:١ — أضف لمسة المطوّر وأخرِج شيئاً **أفضل** من المرجع.
5. **الإصلاح يكون جذرياً وكاملاً** (طبقات حماية + احتياطات)، لا حلول مؤقّتة. اللاعب يجب ألا يرى حالة معطوبة أبداً.
6. **لا تختبر داخل Studio بنفسك** — صاحب المشروع يختبر بعد التسليم. سلّم ملفاً نظيفاً + شرح كيف يجرّب.
7. **بعد كل تعديل:** افحص صياغة Lua (luau)، ابنِ، وتأكد أن XML سليم (`well-formed`) وعدد كتل CDATA كامل، وصفر باك-دور.

## ⚠️⚠️ أهم درس (اقرأه مرّتين): الهندسة الثابتة مقابل هندسة وقت التشغيل (Runtime)

> **سبب تكرار أخطاء «أصلحته بس ما تغيّر باللعبة» هو الخلط بين نوعَي الهندسة. افهم الفرق جيداً قبل أي تعديل على السينما.**

في هذا المشروع توجد العناصر بطريقتين مختلفتين تماماً:

1. **هندسة ثابتة (Static):** أجزاء (`Part`) مكتوبة مباشرة داخل `DonationCity_FINAL.rbxlx` بإحداثيات `CFrame` وحجم `size`. مصدرها `inject_cinema_new.py`. تظهر في فحص الملف XML.
2. **هندسة وقت التشغيل (Runtime):** عناصر **يُنشئها سكربت Lua لحظة تشغيل اللعبة** (`Instance.new` داخل `CinemaSystem`/`CinemaServices`). **لا تظهر إطلاقاً في فحص XML للملف الثابت** — تظهر فقط داخل اللعبة المشغّلة.

**القاعدة الحاسمة:**
- لو طلب المستخدم حذف/تعديل عنصر وأنت ما لقيته في الـXML ⇒ هو **يُبنى وقت التشغيل**. لاحق السكربت اللي ينشئه (ابحث عن اسمه أو نصّه داخل `src/*.server.lua`) وعدّله **هناك**، ثم ابنِ.
- بعد أي تعديل على نص/عنصر runtime، **تحقّق أنه فعلاً مُضمَّن داخل الكتلة `<![CDATA[ ]]>` في الملف النهائي** (مو بس في `src/`). ابحث عن النص داخل `DonationCity_FINAL.rbxlx`.
- أمثلة عناصر runtime في السينما: نص الماركي، محتوى لوحة التعليمات (SurfaceGui)، وكان منها «لاونج VIP» الأصفر (حُذف).

**مثال تحقّق سريع:**
```bash
# هل اختفى نص/عنصر runtime من الملف النهائي فعلاً؟
grep -c "النص_أو_اسم_العنصر" DonationCity_FINAL.rbxlx   # 0 = محذوف/غير موجود
# تحقّق بصري لواجهة السينما بلا Studio:
python3 render_cinema.py    # ينتج cinema_render.png
```

## 5) ⌘ نظام أوامر الدردشة (ميزة قائمة — مرجع)

أُضيف نظام أوامر كامل **قابل للتحكم** من لوحة الإدارة، مبني داخل دردشتنا (بدون أي نظام خارجي).

### الأوامر والمستويات الافتراضية
- 🟢 **للجميع:** `/help` `/clear` `/me` `/roll` `/flip` `/coins` `/tickets` `/online` `/spawn` `/vip`
- 🔰 **للمشرفين (mod فأعلى):** `/announce` `/mute` `/unmute`
- 🛡️ **للأداريين (admin فأعلى):** `/kick` `/pull`(=`/bring`) `/to` `/freeze` `/unfreeze` `/fly` `/give` `/speed` `/heal`

كل أمر يدعم **مرادفات عربية/إنجليزية** (مثل `/طيران` = `/fly`، `/سحب` = `/pull`).

### آلية العمل (مهم للفهم)
- أي رسالة تبدأ بـ `/` → تُلتقط في `sayRemote.OnServerEvent` (في `CustomChat.server.lua`) وتُمرّر إلى `handleCommand` **ولا تُبَثّ كدردشة**.
- `CMD_ALIAS` يحوّل المرادف إلى **مفتاح قانوني (key)**، ثم **بوابة صلاحية موحّدة** تتحقق من `cmdLevel[key]` (المخزّن في DataStore).
- المستويات: `0=الجميع · 2=المشرفون · 3=الأداريون · 99=معطّل`. تُحفظ في DataStore باسم `ChatCmdPerms_v1`، وتُبثّ فوراً لكل العملاء عند أي تغيير.
- **لوحة الإدارة:** تبويب «⌘ الأوامر» (في `CinemaClient.client.lua`) يعرض كل أمر مع ٤ أزرار لاختيار مستواه. الـ backend في `CinemaServices.server.lua` عبر إجراء `setCmdPerm`.
- **لوحة الأوامر للاعب:** زر ⌘ في رأس الدردشة أو أمر `/help` — تبيّن المتاح لك مقابل المقفول.
- **الطيران `/fly`:** زر تبديل (toggle) — نفس الأمر يشغّل ويوقف. WASD للحركة، Space للأعلى، Ctrl للأسفل، Shift للسرعة. `/fly 120` لتحديد السرعة (16–300). يتوقف تلقائياً عند الموت/إعادة الظهور.
- **التجميد `/freeze`:** يُخزَّن في الذاكرة (`frozen[userId]`) ويُعاد تطبيقه عند كل ظهور للشخصية.

### نقاط أمان مطبّقة (من مراجعة Devin)
- `/spawn` فيه **مهلة ٥ ثوانٍ لكل لاعب** تمنع تكرار `LoadCharacter` (إجهاد السيرفر).
- **المكتوم** يُمنع فقط من أوامر **البثّ** (`/me` `/roll` `/flip` `/announce`) عبر مجموعة `BROADCAST_CMD`، لكنه يستطيع استخدام الأوامر الذاتية (`/help` `/clear` `/spawn` …).
- **سبب `/kick`** يمرّ على فلتر روبلوكس (`safeFilter`) قبل عرضه للاعب المطرود.
- لا يمكن كتم/طرد/تجميد من رتبته مثلك أو أعلى (الفحص عبر وزن الرتبة).

## 10) 🧗 نظام الباركور الجديد (كامل) — كيف تكمّله وتعدّله

> الباركور أُعيد بناؤه **من الصفر** بقطع روبلوكس أصلية فقط (Part/Cylinder) داخل `src/ParkourSystem.server.lua` — صفر Union/Mesh. **كل شيء في هذا الملف:** الهندسة + الميكانيكا + الضابط + البوّابة. تعديل أي شيء = عدّل هنا ثم `python3 build_all.py`.

### الفكرة بإيجاز
مسار خطّي صاعد بهدوء: **١٤ منصّة** (مرقّمة 0..13) على **٤ مناطق ملوّنة** بالتقدّم (أخضر ← فيروزي ← برتقالي ← أحمر). نقاط حفظ + حواجز حمراء قاتلة + عوائق دوّارة + منصّة قفز + سقوط = رجوع + وصول للقمة = مكافأة. طابع «أسطح المدينة»: كل منصّة = سطح مبنى خرساني بنوافذ مضيئة + سور بلون المنطقة + زينة.

### الثوابت الأساسية (أعلى الملف ~٥٩–١٠٢؛ ما عدا `REWARD` فقرب منطق النهاية)
| الثابت | القيمة | المعنى |
|--------|--------|--------|
| `ORIGIN_X, ORIGIN_Z` | `-175, 20` | إحداثيات بداية المسار (سماء الركن الشمالي الغربي) |
| `TOP0` | `90` | ارتفاع سطح أول منصّة |
| `RISE` | `3.6` | الصعود بين كل منصّة (قفزة سهلة) |
| `STEP_X` / `STEP_Z` | `14` / `4` | تباعد/انزياح المنصّات |
| `PW, PD, PT` | `11, 11, 1.2` | عرض/عمق/سمك المنصّة |
| `COUNT` | `14` | عدد المنصّات (0..COUNT-1) |
| `REWARD` | `250` | كوينز مكافأة القمة |
| `ENTRY_POS` | `V(-20, 1.3, 60)` | موضع بوّابة الدخول (أرضية، جانب الانطلاق الرئيسي) |
| `EXIT_POS` | `V(6, 5, 60)` | موضع الخروج الآمن |
| `SPAWN_POS` | `V(ORIGIN_X, platTop(0)+3.5, ORIGIN_Z)` | نقطة ظهور اللاعب فوق المنصّة 0 |
| `FALL_Y` | `platTop(0) - 12` | تحتها = سقوط ⇒ رجوع لآخر نقطة حفظ |

دوال الموضع: `platTop(i) = TOP0 + i*RISE` (ارتفاع سطح المنصّة i) و `platCenter(i)` (مركز المنصّة i).

### جداول العناصر (هنا تتحكّم بكل شيء — غيّر المفاتيح فقط)
```lua
local CP_AT     = { [0]="١", [4]="٢", [7]="٣", [10]="٤" }  -- نقاط حفظ مرقّمة (المنصّة → رقم النقطة)
local STRIP_AT  = { [5]=true, [9]=true, [11]=true }         -- بلاطات/أشرطة حمراء قاتلة على هذه المنصّات
local SPIN_AT   = { [8]=1.1, [12]=1.5 }                     -- عوائق دوّارة (المنصّة → سرعة rad/s)
local BOUNCE_AT = { [6]=true }                              -- منصّة قفز نطّاطة
```
حلقة البناء تمرّ على `0..COUNT-1`، تبني كل منصّة وتطبّق عليها ما يخصّها من هذه الجداول تلقائياً.

### كيف تضيف/تعدّل (وصفات جاهزة)
- **زيادة عدد المنصّات:** ارفع `COUNT` (مثلاً 16) — تُبنى الجديدة وتُربط تلقائياً، ثم وزّع عليها نقاط حفظ/حواجز عبر الجداول.
- **إضافة حاجز أحمر قاتل:** أضف رقم المنصّة لـ `STRIP_AT` (مثلاً `[7]=true`) — لمسه يرجّع اللاعب لآخر نقطة حفظ.
- **إضافة نقطة حفظ:** أضف `[رقم_المنصّة]="رقم_النقطة"` في `CP_AT` (الأرقام عربية للعرض).
- **إضافة عائق دوّار:** `SPIN_AT[رقم] = السرعة` (rad/s؛ الأكبر أصعب).
- **منصّة قفز:** `BOUNCE_AT[رقم] = true`.
- **تغيير ألوان المناطق:** عدّل دالة `zoneColor(i)` أو ألوان `GREEN/TEAL/ORANGE/RED` أعلى الملف.
- **تغيير الصعوبة:** قلّل `RISE`/`STEP_X` (أسهل) أو زِدها (أصعب)، أو قلّل عدد مفاتيح `STRIP_AT`.

### أدوات البناء (استعملها لأي قطعة جديدة — لا تكرّر كوداً)
- `mk(name, size, posOrCF, color, material, parent, canCollide)` → صندوق `Part` (Anchored دائماً). `posOrCF` يقبل `Vector3` أو `CFrame`.
- `mkCyl(name, height, dia, centerY, x, z, color, material, parent, canCollide)` → أسطوانة عمودية.
- `signGui(part, text, color, size)` → لافتة نصّية تُقرأ من الوجهين.

### الدوال المفتاحية للميكانيكا
- `startRun(player)` → يبدأ الجولة + ينقل اللاعب لـ `SPAWN_POS` + يشغّل حلقة التقدّم. **بوّابة الدخول تستدعيها بعد العدّ التنازلي.**
- `stopRun(player)` → ينهي الجولة وينقل لـ `EXIT_POS`.
- `respawnAtCheckpoint(player)` → يرجّع اللاعب لآخر نقطة حفظ (عند لمس حاجز أحمر أو السقوط تحت `FALL_Y`).
- `teleportTo(player, cf)` · `rlAllow(userId)` (حارس إغراق Remotes).

### 👮 ضابط الشرطة البحريني (عند بداية المسار، ~٣٧٢)
- يُبنى **بقطع أصلية فقط (~٤٥ قطعة)**، Model باسم `PoliceOfficer`، **Anchored بالكامل** (بلا تصادم/فيزياء = صفر استهلاك).
- يقف **جانب** نقطة الانطلاق على منصّة البداية ويواجه اللاعب القادم (لا يعترض المسار).
- الهندسة مترجمة من مجسّم بلندر معتمد: تُحوّل إحداثيات بلندر (X يمين، Y أمام/خلف، Z أعلى) إلى إطار الضابط المحلي عبر مصفوفة دوران (`base`)، فكل القطع توضع نسبةً لاتجاهه.
- الزي: بدلة كحلية + باكِت أزرار ذهبية + بريه عنّابي + شارة كاب + نجوم رتبة + **علم البحرين** على الكُمّ الأيمن + ملامح وجه + بوت أسود.
- **لتعديله:** غيّر موضعه/اتجاهه عبر متغيّر `base` في تلك الدالة.

### 🚪 بوّابة الدخول 3D + ProximityPrompt + العدّ التنازلي (~٥٨٨–٧٦٠)
استُبدل **البدء التلقائي باللمس** بـ**بدء متحكَّم** (يمنع الانطلاق بالغلط):
- **الهندسة (قطع أصلية):** قاعدة إطلاق دائرية + حلقة ضوء خضراء (قرص نيون) + ٣ أذرع ضوء دوّارة + قوس بعمودين خرسانيين + لافتة «برج الباركور / اضغط E للبدء» + عمود ضوء يطلع للسماء + فقاعة عدّ تنازلي (BillboardGui).
- **التشغيل:** `ProximityPrompt` اسمه `StartParkour` على `promptPart` — `KeyboardKeyCode=E`, `MaxActivationDistance=14`, `HoldDuration=0`.
- **عند الضغط (`gatePrompt.Triggered`):** يتحقّق أن اللاعب ليس داخل جولة + لا يوجد عدّ جارٍ (علم `gateCountingDown`) ⇒ يعطّل البرومبت ⇒ يعرض **٣·٢·١** (ثانية لكل رقم عبر `setGateNumber`) + إشعار ⇒ ينادي `startRun(player)` ⇒ يعيد تفعيل البرومبت.
- **دوران الأذرع:** حلقة `task.spawn` تدوّر الأذرع **فقط عند وجود لاعب ضمن ٨٠ ستد** من `ENTRY_POS` (تنام `task.wait(0.5)` عند الخمول = صفر استهلاك).
- **لتعديل العدّ:** غيّر قائمة `{ "٣", "٢", "١" }` داخل `gatePrompt.Triggered`. **لموضع البوّابة:** `ENTRY_POS`. **لمدى التفعيل:** `MaxActivationDistance`. **لمسافة تشغيل الدوران:** الرقم `80`.

### الأداء (لا تكسره)
كل القطع `Anchored` (صفر فيزياء). حلقة المنطق الوحيدة تعمل **فقط أثناء جولة نشطة** وتتوقف عند الخمول. **أي عنصر تضيفه:** ثبّت `Anchored=true` ولا تشغّل حلقات دائمة بلا شرط قرب لاعب.
