# Delivery Game 3D — لعبة توصيل الموظفين

لعبة قيادة ثلاثية الأبعاد واقعية مبنية بـ Three.js + TypeScript + Vite.

## 🎮 الفكرة
اللاعب يبدأ يوم عمله كسائق توصيل موظفين:
- يخرج من منزله مشياً
- يركب سيارته
- يذهب إلى بيوت الموظفين ليصطحبهم
- يوصّلهم إلى مقر العمل
- يتوقف في محطة البنزين عند الحاجة
- يتقدّم في 10 مراحل بصعوبة متزايدة وسيارات مختلفة

## 🎛 التحكم
| المفتاح | الوظيفة |
|---|---|
| `W` `A` `S` `D` | حركة (مشي أو قيادة) |
| `Shift` | ركض (مشي فقط) |
| `Space` | فرامل يد (قيادة) |
| `H` | بوق |
| `E` | دخول / خروج من السيارة، أو تفاعل مع محطة البنزين |
| `C` | تبديل كاميرا (خلف السيارة / داخلي / بعيد) |

## 🚀 التشغيل المحلي
```bash
npm install
npm run dev
```

ثم افتح http://localhost:5173

## 📦 البناء
```bash
npm run build
npm run preview
```

## 🏗 البنية
```
src/
├── core/        # Engine, Input, Audio (Web Audio procedurally generated)
├── world/       # City, Buildings, TrafficLights, TrafficAI, NPC
├── player/      # Player + walk controller
├── vehicle/     # Car, CarCatalog (6 cars), CameraRig
├── gameplay/    # Mission, StageManager, FuelSystem
├── ui/          # HUD, MiniMap
└── utils/
```

## ✨ الميزات
- 🏙 مدينة شبكية 7×7 بلوكات مع شوارع وأرصفة وإشارات مرور حقيقية
- 🏠 تنوع بصري: 3 أنماط مباني (بيوت، شقق، محلات)
- 🚗 6 سيارات مختلفة (هاتش، سيدان، SUV، ميني فان، ميني باص، بيك أب)
- 🎯 فيزياء قيادة Bicycle Model مع Ackermann steering
- 👥 شخصيات Humanoid + مارّة + حركة مرور AI
- ⛽ نظام وقود كامل + محطات بنزين + موظفي تعبئة
- 🗺 خريطة مصغرة كانفاس 2D مع أسهم ديناميكية
- 🌅 دورة نهار/ليل + إضاءة ديناميكية + ظلال PCF
- 🔊 صوت محرك procedural يتغير مع RPM + بوق + ضوضاء مدينة
- 🌟 نظام تقييم نهاية المرحلة (نجوم) + مكافآت ونظام أرباح
- 📱 واجهة عربية RTL احترافية

## 🎨 الأسلوب البصري
Stylized Realistic — مجسمات بسيطة لكن مُعتنى بها مع إضاءة PBR + ظلال + Tone Mapping.
