# --- MusicBot v2 (Lavalink + wavelink) -----------------------------------
#
# This bot streams audio through a Lavalink server (separate fly.io app
# `music-lavalink-am`). Lavalink itself opens the Discord voice WebSocket
# and UDP socket and handles the DAVE/MLS handshake natively (libdave
# >= 0.1.3, bundled in Lavalink 4.2.x). The Python bot only sends slash
# commands and forwards voice state updates -- it never opens a voice
# connection itself, so `davey` and `PyNaCl` are NOT required and the
# `[voice]` extra MUST NOT be installed (it would pull `davey` into the
# image needlessly and add ~30MB of native code).
#
# wavelink 3.x is the canonical Lavalink v4 client for discord.py.
discord.py>=2.7.0
wavelink>=3.5.2
python-dotenv==1.0.1
